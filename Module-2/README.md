# Module 2 — Analytics Pipeline

This folder contains the complete Titanic analytics and predictive-modeling submission.

## Files

- `01_eda.ipynb` — Tasks 1–6: profiling, missing-value analysis, EDA, correlation analysis, data story, and standardization sanity check.
- `02_modeling.ipynb` — Tasks 7–15: stratified split, train-only preprocessing, classification, imbalance comparison, Random Forest tuning/OOB, regression, evaluation, and pipeline persistence.
- `titanic.csv` — generated by `01_eda.ipynb` immediately after the single `sns.load_dataset("titanic")` call. This is the offline fallback.
- `titanic_pipeline.joblib` — generated by `02_modeling.ipynb` and contains the complete preprocessing + final estimator pipeline.
- `charts/` — saved supporting plots.
- `requirements.txt` — Python dependencies.
- `.gitignore` — common files excluded from Git.

## How to run

From the `analytics` directory:

```bash
jupyter notebook
```

Run `01_eda.ipynb` from top to bottom first. It creates `titanic.csv`.

Then run `02_modeling.ipynb` from top to bottom. It reads the committed CSV and creates `titanic_pipeline.joblib`.

## Important design choices

The raw dataset is loaded with `sns.load_dataset("titanic")` exactly once. The modeling notebook does not call `sns.load_dataset()` again.

For modeling, preprocessing is implemented using scikit-learn pipelines so that imputation, one-hot encoding, and scaling are fitted only on the training split and then applied to the test split.

SMOTE is placed inside an imbalanced-learn pipeline so that oversampling is performed only on training folds.

The final `.joblib` artifact is a complete pipeline rather than a bare estimator, allowing raw input data to be passed directly to the saved model.
